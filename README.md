## 內容原則（不可寫錯）

1. **不提那張 12 週通用目標表**——它是所有新人共用的版本，與實際派工不符。
2. **課程狀態一律寫「已完成內部試教、教材持續修正中」**，
   不可寫成已對外開課或教材已定稿。
3. **PRD 機器人不可寫成已全面上線**，實際是約 10 位跨部門同事測試中。
4. **「節省近 90%」全篇標示為「推估」**，並在 P23 說明推估依據與後續可實測。
5. **名稱區分**：業務流程叫「神秘客訪問電話」，系統叫「神秘客評分系統」
   （短稱「神秘客系統」）。
6. **時間順序**：對內系統做在前（第 1–3 個月），對外課程在後（第 4 個月至今）。
   第四章是依性質分類、不依時間，扉頁講稿有說明這件事。
7. 配色：深藍 `#2B2D5C`、薰衣草紫 `#D6D9F0`、奶油黃 `#F7F1CE`、橘紅重點 `#D95F2B`。
