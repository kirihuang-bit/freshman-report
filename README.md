程曦資訊整合股份有限公司｜創新研發部｜產品工程師 黃家朗
上台口頭報告 30 分鐘（不含 Q&A），共 35 頁。

## 檔案

| 檔案 | 用途 |
|---|---|
| `黃家朗新人報告.pptx` | **交付物**。16:9，講稿寫在每頁的備註欄 |
| `report/outline.md` | 內容母稿：逐頁大綱＋逐頁講稿＋待補清單 |

## 重新產出簡報

```bash
npm install pptxgenjs      # 只需第一次
node report/build_pptx.js
```

改內容請改 `report/outline.md`（記錄用）與 `report/build_pptx.js`（實際產出），
講稿在 `build_pptx.js` 底部的 `NOTES` 陣列。

## 還要補的東西

簡報裡橘紅色的 `【待補：…】` 都是我沒有的資料，請自行填入後重新產出：

- 學校科系與畢業年、興趣
- 到職前的公司、職稱與任職起訖
- 四門課的時數、面向對象、教材頁數／案例數
- 課程預計開賣時間
- 神秘客系統的上線日期、使用單位數、使用人數
- 其他對內支援與小工具的項目清單（P29 整頁待填，用不到可整頁刪除）
- 四個月工時分佈的實際百分比（目前是推估值）

圖片則是灰色虛線的佔位方塊，依 `report/assets/README.md` 的檔名放進去即可，
不放也能正常產出簡報。

## 內容原則

1. **不提那張 12 週通用目標表**——它是所有新人共用的版本，與實際派工不符。
   第三章改用「我的三階段工作主軸」，期間以月份標示，第三階段寫「第 4 個月至今」。
2. **「節省近 90%」全篇標示為「推估」**，並在 P25 說明推估依據與後續可實測。
3. **課程狀態一律寫「已完成內部試教、教材持續修正中」**，
   不可寫成已對外開課或教材已定稿。
4. **PRD 機器人一律寫「約 10 位跨部門同事測試中、尚未全面開放」**，不可寫成已全面上線。
5. 配色沿用參考範本：深藍 `#2B2D5C`、薰衣草紫 `#D6D9F0`、奶油黃 `#F7F1CE`、
   橘紅重點 `#D95F2B`。
